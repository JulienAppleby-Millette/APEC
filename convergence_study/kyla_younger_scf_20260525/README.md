# Kyla Younger SCF Convergence Study

This directory contains the independent Quantum ESPRESSO SCF convergence
campaign used in Paper 1.

The raw outputs are in `raw/`. Filenames use the form
`{functional}_{ecut_ry}_{kmesh}_scf.out`, where `kmesh` denotes an
`N x N x N` Monkhorst-Pack mesh. The calculations use a 40-atom tetragonal
BaTiO3 supercell.

Processed outputs are generated by:

```bash
python papers/paper1-posterior-certificates/scripts/analyze_kyla_scf_convergence.py
```

The processed CSV and JSON summaries are in `processed/`, and the manuscript
figure is written to `../figures/fig4_scf_convergence.pdf` and `.png`.

Interpretation: these calculations certify the total-energy and ground-state
SCF convergence scale. They do not replace explicit DFPT convergence studies
for soft phonons, Born effective charges, dielectric tensors, or derived
electro-optic response.
